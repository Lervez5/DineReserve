# 🍽️ DineReserve – Online Restaurant Reservation System (Django)

  

## 📌 Overview

  

**DineReserve** is a Django-powered web application that streamlines the process of booking tables at restaurants. It offers a smooth and intuitive interface for customers to make reservations and enables restaurant managers to track and manage bookings in real-time.

  

---

  

## 🎯 Key Features

  

- 📅 **Real-Time Reservations** – Users can view available tables and make bookings instantly.

- 📋 **Reservation Management** – Both users and staff can manage upcoming reservations.

- 📊 **Admin Dashboard** – A user-friendly backend for restaurant staff to oversee operations.

- 💳 **Mpesa payment** - Integration with Mpesa payment gateway

- 📱 **Responsive Design** – Fully optimized for mobile, tablet, and desktop.

## 🚀 Getting Started

  

Follow these steps to set up the project locally:

  

### 1. Clone the Repository

  

```bash

git  clone  https://github.com/Lervez5/DineReserve.git

cd  DineReserve

```

  

### 2. Create & Activate Virtual Environment

  

```bash

python -m venv env

source  env/bin/activate  # Windows: env\Scripts\activate

```

  

### 3. Install Requirements

  

```bash

pip install -r requirements.txt

```

  

### 4. Run Migrations

  

```bash

python manage.py makemigrations

python manage.py migrate

```

  

### 5. Start Development Server  

```bash

python manage.py runserver

```

  

### 6. Access the App

  

Open your browser and go to:

[http://127.0.0.1:8000](http://127.0.0.1:8000)
